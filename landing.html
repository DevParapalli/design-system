( THE POINT )

I check on my machines at 2am, in a dark room, on a phone. The only thing that should glow is the thing that is wrong.

Devansh Parapalli
( WHAT IT DOES )

Four things, done properly

Watches hosts and services

CPU, memory, disk, uptime and the state of every container. One line each. Click a line for the rest.

Alerts you can test first

Write a rule and see how often it would have fired over real history before you save it. No surprise pager at midnight.

Says what to do

Every alert carries the note you wrote when you were calm. Future you reads it at 2am and knows where to start.

Guesses where things are going

Trends continue as a dotted line, so you find out about the disk on Tuesday instead of Friday night.
